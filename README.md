# 📖 文本转语音阅读器 (TTS Reader)

一个纯前端的文本转语音阅读器，基于浏览器内置 Web Speech API 构建，无需任何后端服务。支持 Markdown 语法过滤、AI 智能总结、断点记忆、历史记录管理等功能。

> ✨ 开箱即用 — 只需一个 HTML 文件，双击即可运行

## ✨ 功能特性

### 核心功能
- **浏览器语音合成** — 使用 Web Speech API，无需额外依赖
- **Markdown 语法过滤** — 自动跳过 `#`、`**`、`[]()` 等 Markdown 符号
- **智能分句高亮** — 按 `。！？；.!?\n` 分割句子，实时高亮当前朗读位置
- **点击朗读定位** — 点击阅读区任意句子，从该处开始朗读
- **语速调节** — 0.3x ~ 3.0x 滑块控制

### 🤖 AI 总结
- 深入剖析 / 一句话总结 / 核心观点 / 关键词提取
- 支持多种 AI 提供商：OpenAI、Anthropic、DeepSeek、Ollama、硅基流动、阿里云、腾讯云等
- AI 结果自动缓存，无需重复调用 API
- 无 API 时自动切换本地分析模式

### 📜 历史记录
- 自动保存朗读记录至左侧面板
- 支持恢复上次进度（百分比显示）
- 回收站机制：删除可恢复，防止误删
- 最多保留 50 条记录，按时间倒序

### 🎨 主题与模式
- **纸质模式** — 暖色调模拟纸张阅读体验
- **深色模式** — 护眼低蓝光夜间主题
- **极简阅读模式** — 沉浸式全屏阅读，隐藏所有控件

### 📊 进度管理
- 实时显示已读/总字符数与百分比
- 点击进度条跳转至任意位置
- 断点记忆：关闭浏览器后自动恢复，7 天内有效

### ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `空格` | 暂停 / 继续 |
| `←` | 跳到上一句 |
| `→` | 跳到下一句 |
| `↑` | 语速 +0.1 |
| `↓` | 语速 -0.1 |
| `Ctrl + Enter` | 开始朗读 |
| `Ctrl + S` | 停止朗读 |
| `Ctrl + P` | 暂停 / 继续 |
| `Esc` | 退出极简模式 |

## 🚀 快速开始

### 方式一：直接打开（最简单）

直接双击 `tts-reader.html` 文件，即可在浏览器中使用。

> ⚠️ 部分浏览器可能限制 `file://` 协议下的剪贴板 API，建议使用本地服务器。

### 方式二：本地服务器

```bash
# Python
python server.py

# 或 Node.js
npx serve .

# 或 PHP
php -S localhost:8080
```

然后访问 `http://localhost:8080/tts-reader.html`

### 方式三：在线部署

本项目为纯静态资源，可一键部署到以下免费平台：

- **GitHub Pages** — 推送至仓库后在 Settings → Pages 中启用
- **Vercel** — 导入 GitHub 仓库自动部署
- **Netlify** — 拖拽文件夹即可部署
- **Cloudflare Pages** — 连接仓库自动构建

详细部署指南请参考 [DEPLOY.md](DEPLOY.md)

## 📋 使用流程

1. **输入文本** — 在「原文输入」区域粘贴或输入要朗读的文本
2. **选择语音** — 从下拉菜单选择合适的语音（支持中英文）
3. **调节语速** — 拖动语速滑块至舒适速度
4. **开始朗读** — 点击「开始朗读」按钮或按 `Ctrl + Enter`
5. **交互控制** — 朗读过程中可暂停、跳转、点击句子重新定位
6. **AI 总结** — 配置 API 后点击右侧 AI 面板按钮获取智能分析

## 📝 AI 配置说明

在右侧面板点击「配置 AI 模型 API」，填写以下信息：

| 字段 | 说明 |
|------|------|
| 模型提供商 | 选择 API 服务商（OpenAI / Claude / DeepSeek 等） |
| API 地址 | 自动填充默认地址，也支持自定义 |
| API Key | 你的 API 密钥 |
| 模型名称 | 如 `gpt-4o-mini`、`claude-3-sonnet` 等 |

配置完成后可点击「测试连接」验证配置是否正确。
